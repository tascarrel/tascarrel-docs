# Security Policy

Tascarrel is experimental and does not currently promise a security support
window, stable hardening guarantees, or backward-compatible state.

Read the [Isolation Model](/docs/getting-started/isolation-model) for the
intended boundaries and residual risks.

## Report a Vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to [security@silitics.com](mailto:security@silitics.com) with:

- The affected Tascarrel version and host platform.
- The workspace features required to reproduce the issue.
- A minimal reproduction or clear sequence of actions.
- The impact you observed and any suggested mitigation.

Use the public [issue tracker](https://github.com/tascarrel/tascarrel/issues)
for non-sensitive reliability and usability problems.
